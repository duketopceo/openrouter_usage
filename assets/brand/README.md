# Brand assets (proposal)

Proposal only: the owner signs off logos.

**Mark.** A gauge on a 64 px grid. An open ring (radius 22, stroke 6, round caps) spans 270 degrees and is open at the bottom. A copper needle runs from the centre to the upper right. A hub dot (radius 4.5) sits on the pivot. The ring is the budget; the needle is spend. Hand-written paths, no stock icons, no raster source.

**Colour.** Ink `#1C1B18` / copper `#9A4A0C` on paper `#FAF8F4` (`logo.svg`); `#ECE8DF` / `#E8A063` on `#14130F` (`logo-dark.svg`). Contrast is in `DESIGN.md`.

**Files.** `logo.svg`, `logo-dark.svg`, `wordmark.svg` (text uses a JetBrains Mono stack, not outlined yet), `social-card.svg` (placeholder `$—` values, no real data). PNG previews are rendered with `resvg` and `oxipng`.

At 16 px the ring and needle both stay distinct; the hub dot merges into the needle, which is fine.
